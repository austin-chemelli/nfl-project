# ADR 0010: The first public lock waits for the approaches

Status: accepted 2026-10-26. Supersedes the "Week 9 market-only lock" decided 2026-10-23.

## Context
The POC can lock market, Elo and naive lines today. Austin prefers the first public record to be the approaches, not a placeholder, and the project runs on whatever time is available rather than a calendar.

## Options
1. Lock the next available week with the POC models; approaches join later.
2. First public lock when Traditionalist, Analyst, Sharp, the ensemble and the ledger exist (M1–M4), after one unpublished dry-run week.

## Decision
Option 2. No calendar targets: the sequence M1 → M2 → M3 → M4 is the critical path, and the first lock is the first full NFL week after a clean dry run. Whatever approaches are test-green at that point lock; the rest join when ready, each starting its own public record.

## Consequences
Live weeks before the approaches exist are forgone; the record is shorter but clean. Every public scorecard shows "weeks tracked" per model, since approaches may start on different weeks. M5–M8 are explicitly off the critical path.
