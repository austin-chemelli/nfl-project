# ADR 0011: Code MIT, published derived data CC-BY-SA 4.0

Status: accepted 2026-10-23.

## Context
nflverse data is CC-BY; FTN charting and participation data are CC-BY-SA 4.0 (share-alike). Derived tendency tables and features are published.

## Decision
Code under MIT. Published derived datasets (tendencies, features, predictions, scorecards) under CC-BY-SA 4.0 with attribution to nflverse and FTN Data. README carries the credits and the "fan-made, not affiliated with the NFL" disclaimer; no team or league logos.

## Consequences
Anyone redistributing the derived data must share alike; a portfolio project loses nothing. Paid-source data never enters the published store (ADR 0001).
